# Manufacturing Quality Analysis Using MySQL

## Project Overview

This project uses MySQL to analyze synthetic manufacturing quality and sales data. It calculates important KPIs and compares plant, supplier, department and product performance.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## KPIs Analyzed

- Total Revenue
- Production Quantity
- Rejected Quantity
- Rejection Rate
- Parts Per Million (PPM)
- RMA Rate
- Supplier Quality Score

## SQL Skills Demonstrated

- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- GROUP BY
- HAVING
- CASE
- Common Table Expressions (CTEs)
- Aggregate functions
- Window functions
- RANK()
- Date functions

## How to Run

1. Install MySQL and MySQL Workbench.
2. Open MySQL Workbench.
3. Create a new SQL tab.
4. Open `manufacturing_quality_analysis_mysql.sql`.
5. Run the complete script.
6. Review the results of each analysis query.

## Data Disclaimer

The dataset is synthetic and created for learning and portfolio purposes. It does not contain confidential company or customer information.
